# Berna Focus 3.0.0

This release contains 160,000 localized reminder phrases: 10,000 for each of 16 language variants.

Each language contains five categories × two moments × 1,000 phrases:
- T-10 preparation
- exact-time action

The reminder copy is intentionally short, readable, warm and action-oriented. The content avoids shame and focuses on the next concrete step.

Localized academic content ships at 1,400 phrases per language across seven disciplines and two moments.
