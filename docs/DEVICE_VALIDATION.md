# Device validation

Use a Huawei/AppGallery-capable device where possible.

- [ ] Fresh install opens the real UI.
- [ ] Notification and exact-alarm access can be granted.
- [ ] One-time commitment produces exactly two visible reminders: T−10 and T.
- [ ] No visible reminder occurs at T+5; the occurrence simply expires if unresolved.
- [ ] Delete/cancel removes future reminders.
- [ ] Reboot reschedules only future valid occurrences.
- [ ] One-time never repeats.
- [ ] Daily, weekdays, weekends and specific-day recurrence work.
- [ ] All 16 language options work, including pt-BR/pt-PT and zh-CN/zh-HK.
- [ ] Important Events and Academic Focus paywalls remain locked until validated purchase.
- [ ] Huawei IAP validation uses the owner-provided public key.
- [ ] Previously validated Premium remains available offline.
