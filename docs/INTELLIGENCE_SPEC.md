# Focused Mind offline intelligence

Focused Mind uses deterministic, privacy-friendly intelligence rather than fake AI claims:

- detects commitments scheduled within a 20-minute conflict window;
- selects reminder phrases by language, category, discipline and moment;
- limits repeated reminder reuse locally;
- keeps a 5-minute response window and silently expires unresolved occurrences;
- adapts progress messaging frequency;
- uses streak/completion state for reward calculation;
- never sends random motivational notifications without a commitment.

This layer is intentionally offline-first. Future cloud intelligence can be added without making the core commitment flow dependent on connectivity.
