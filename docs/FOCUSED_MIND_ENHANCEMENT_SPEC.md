# Focused Mind — Enhancement Specification

The product is a personal commitment system, not a generic task list.

Core flow: Intention → Commitment → Preparation → Reminder → Action → Completion → Reward → Progress → Consistency.

Reminder contract: exactly two user-visible reminder notifications per occurrence — 10 minutes before and at the scheduled time. A third internal timer may run at T+5 only to close an unresolved occurrence; it must never create a notification.

Recurrence is opt-in. One-time commitments never repeat. Recurring commitments create their next occurrence only after the current occurrence is resolved or expires.

Premium products are non-consumable AppGallery purchases. Important Events unlocks the event category; Academic Focus unlocks all seven academic disciplines.

The core application remains useful offline.
